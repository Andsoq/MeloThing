07 — Documentação

Sobre o projeto

O MeloThing organiza o ensino musical em trilhas, com cursos gratuitos e pagos. A MelodI.A é a assistente virtual que orienta estudantes na escolha de trilhas, explica conceitos, conduz a prática e ajuda na retomada dos estudos.

A interface roda inteiramente no navegador: HTML, CSS e JavaScript. Uma máquina de estados conduz os cinco fluxos de diálogo, a Web Audio API sintetiza notas e batidas, e um modelo de Markov sorteia frases curtas para o treino de ouvido.
